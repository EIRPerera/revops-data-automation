## 🚀 How to Initialize the Repository

### 1. Requirements
* An active instance of **n8n** (Cloud or self-hosted Docker deployment setup).
* Valid API credentials for **HubSpot (Private Apps)**, **Apollo.io**, **Apify**, **OpenAI**, and **Slack**.

### 2. Execution Guide
1. Navigate into any specific project directory above.
2. Open and copy the raw contents of the `workflow.json` asset.
3. In your n8n workspace dashboard, create a new canvas and simply press `Ctrl + V` (or `Cmd + V`) to paste the entire structural node configuration.
4. Re-link your specific environment credentials to the HTTP, Webhook, or native application nodes, and shift the execution toggle to **Active**.
